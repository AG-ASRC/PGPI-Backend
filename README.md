# PGPI-Backend
Backend de la solution PGPI (Plateforme de Gestion et de Pilotage d'Infrastructure)

## Configuration de l'environnement virtuel

### Créer le venv

```bash
python3 -m venv .venv
```

### Activer le venv

#### Windows

```powershell
.\.venv\Scripts\activate
```

#### Linux / macOS

```bash
source .venv/bin/activate
```
